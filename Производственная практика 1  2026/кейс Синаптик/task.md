# Задание: Генерация продуктовых гипотез

Вы - аналитик интернет-сервиса, который построен по классической клиент-серверной архитектуре и продается в виде подписок по набору тарифов. 

Клиент реализован в виде мобильного приложения для разных платформ: андроид, эпл, хуавей
Команда сопровождения подготовила дамп серверной БД и выгрузку логов клиентов по инцидентам. 
Отдельно выгружена структура всех таблиц. 
## Что нужно сделать
1. Проанализировать и сопоставить данные по клиентам и их действиям
2. Попытаться сгенерировать продуктовые гипотезы, например: 
- среди пользователей  есть те, кто каждый раз заводит новый аккаунт, чтобы пользовать триал-периодом. Как их определять, есть ли в логах какие-то косвенные признаки
- бесплатный тариф имеет лимиты трафика, которые сделаны на глаз 500 Мб в день и 15 Гб в месяц. Для расширения лимита надо смотреть рекламу. Выяснить, какие объемы оптимальны, исходя из реального потребления трафика на бесплатном тарифе.
- как долго люди пользуются бесплатным тарифом, прежде чем купить тариф. Всегда ли это происходит после триала, сколько клиентов покупает тариф без использвоания триала
- на основе логов инцидентов найти паттерны поведения, которые приводят к типовым ошибкам.
- и т.д.

Каждая гипотеза оценивается отдельно

## 2. Чем занимается компания

«Синаптик» разрабатывает цифровые продукты и внутренние системы для бизнеса: не типовые решения, а инструменты под процессы и модель управления конкретного заказчика. Особенно компания сильна в проектах, где нужно навести порядок в процессах, данных и исполнительской дисциплине.

Основные направления:

- **Интеллектуальные ERP-системы** для контроля и прогнозирования работы производственных предприятий;
- **Системы автоматизации** бизнес-процессов;
- **Разработка мобильных приложений** (в том числе по аутсорс-модели);
- **Разработка «под ключ»** — от идеи и discovery-этапа до готового продукта;
- **Аутстаф** — усиление команд заказчиков ИТ-специалистами.

Компания ориентирована на производственные предприятия, для которых разрабатывает ERP-решения, в том числе системы складского учёта и автоматизации складов. Среди публичных кейсов — доработка мобильного приложения для компании «Рынок Р».
